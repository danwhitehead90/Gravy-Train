About Gravy Train


Gravy train is a completely free tool aimed to help commuters traveling between München and Donauwörth plan their connections.

The system consists of 2 parts, a local server back end, used for gathering the data and pushing to GIT, and a static GIT Hub page acting as the web server.

The queries executed by the local server are automatically scheduled as 'cron' jobs, which, when finished, push the servers result as JSON files to the site.
